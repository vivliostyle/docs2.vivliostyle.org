# 要求された表示を実際に実現する

記録日: 2026-10-30

## 起きたこと

ユーザーはCodexのDiff画面で長い行が切れて読めないため、変更箇所を折り返して読める形で表示するよう求めた。私は対象のDiff画面ではなくリポジトリの別のコミット差分を出し、その後もコードブロックや長い行の再掲を「折り返して表示した」と誤って扱った。ユーザーに何度も同じ要望を言わせた。

## 次回の対応

- 「画面の行を折り返す」「読めるように表示する」などの要望では、まずユーザーが示した画面・ファイル・差分そのものを対象にする。別のリポジトリ差分や要約へ置き換えない。
- UIを直接変更できない場合でも、任意テキストの表示が求められているなら、内容を適切な長さで実際に改行してチャットに表示する。長い一行をコードブロックに入れただけで、折り返しを実現したと主張しない。
- 変更表示では、添付画像と会話の直前の文脈を照合して対象ファイルと言語を特定する。画像に表示された変更をそのまま読めない場合は、画像から読める範囲と元ファイルから確認した内容を区別する。
- 「できた」と述べる前に、返答の各行が実際に読みやすい長さで改行されているかを確認する。
