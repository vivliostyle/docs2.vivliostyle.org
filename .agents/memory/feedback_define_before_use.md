会話の中で「セクション #1」「あれ」「先ほどの」のような略記や番号参照を使うときは、**初出時に必ず明示的な定義を添える**こと。

**Why:** ユーザーが「定義なしに勝手に用語を決めないで。『セクション #1』は『レスポンシブ画像ガイド』を指しているの？」と指摘した。記事内のサブセクションと記事全体のどちらを指すのか曖昧で、誤解を招いた。

**How to apply:**
- 番号や略語の初出時は「`responsive-images.md` 内の `### 1. ...` サブセクション（以下「#1」）」のように、**フルパス＋スコープ＋略記**をセットで提示する
- 既存の名称（ファイル名・記事タイトル・見出し全文）があるなら、勝手に新しい呼称を作らず既存のものを使う
- 略記を後から導入する場合は「以下、これを X と呼びます」と明示する
