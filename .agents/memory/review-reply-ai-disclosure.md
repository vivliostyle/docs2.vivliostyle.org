# レビュー返信にも AI の関与を表示する

2026-11-27、小形の指示（PR #117）「そうではなく、AI_POLICY.mdに準じた表示して。何回も同じことを書きたくないので、記録して」

AI が GitHub のレビュー返信を書くときも、[AI_POLICY.md](../../AI_POLICY.md) の PR 本文の開示形式を使う。
返信の末尾に `Assisted-by: <道具名>:<実際に使用したモデル ID>` を独立した行で記す。
続く `<details>` の見出しは返信と同じ言語にし、日本語なら「AI の使い方」とする。
人が決めたこと、AI が担当したこと、人が実際に確認したことを書く。
人による修正内容の確認がこれからなら、その状態を明記する。
