# push 後はビルドと preview を更新してレビューする

記録日: 2026-10-30

## 決まり

- push のたびに、レビューを始める前にサイトをビルドし直し、ローカル preview を再起動する。
- ブラウザーのリロードだけでは、ローカルの preview が配信しているビルド済みファイルやプロセス内の古い内容が更新されないことがある。更新後の内容が配信されていることを確認してからレビューする。
- 確認には、変更したページの見出しや本文を `dist/` と preview の応答の両方で照合する。

## 今回の経緯

2026-10-30、push 後に変更履歴をレビューする際、既存の Astro preview がビルド前から起動していたため、ブラウザーをリロードしても更新が表示されなかった。ビルドをやり直して preview を再起動した後、`localhost:4321/ja/changelog/` から更新済みの見出しを確認できた。
