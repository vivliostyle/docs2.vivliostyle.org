ユーザーが日本の電子書籍出版業界の知識（電書協→電書連の改名、PUBFAN / ブックリスタ等の自費出版アグリゲータ等）を直接提示した場合、私が同じ事実を別途検索で確認しに行くのは時間の無駄であり、ユーザーの専門性に対して失礼にあたる。

**Why:** ユーザー（ogwata@vivliostyle.org、Vivliostyle 開発者）から「電書協は改名している」「日本でよく知られた自費出版アグリゲータは PUBFAN とブックリスタ」のような情報を提示された直後に、私が WebSearch を実行しようとして拒否された。ユーザーの業界知識を素直に取り入れるべき場面で、不要な裏取りに走った。

**How to apply:**
- ユーザーが固有名詞・組織名・サービス名・改名情報等を提示した場合は **そのまま受け入れて文書に反映** する
- ただし、「具体的にこの組織がこういう運用をしている」のような **行為・挙動の主張** は、ユーザーが「私は知らない」と明示した場合は推測で書かない
- 追加調査が必要と判断した場合は「調査してよろしいですか？」と先に確認する。勝手にサーチを開始しない
- ユーザーが「調査することは可能ですか？」のように明示的に依頼した場合は積極的にサーチする
