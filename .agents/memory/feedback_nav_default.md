新規ドキュメントセクション・新規ページ群をサイトに追加する作業では、以下の主要導線への配置を **明示的に検討項目として提示**し、ユーザーの承認を得る:

- グローバルナビゲーション（DocsLayout.astro の navLinks）
- トップページのリンク
- パンくず（Breadcrumb.astro の sectionNames）
- サイドバーのページ順序

**Why:**

Issue #15「New Features」セクション実装時、Issue に明記がないことを理由に DocsLayout.astro の navLinks への追加を独自判断で見送り、トップページからのリンクのみで実装した。ユーザーから「グローバルナビに、なぜ「新機能ガイド」がないの？」と指摘を受けた。新規セクションの導線可視化は当然の基本要件であり、Issue に書かれていなくとも省略してはならない。

**How to apply:**

- Issue に「グローバルナビに追加する」と書かれていないからといって、「スコープ外」として扱わない
- 「Issue 指定外なので含めない」「Issue が言及していないから保守的に省略」という判断は禁止
- 新規セクション追加の方針を提示する際、グローバルナビへの配置可否（位置・ラベル・ドロップダウンか単独リンクか等）を必ず提示項目に含める
- 既存セクション（Product / Reference / FAQ 等）と同列の重要度として扱う
