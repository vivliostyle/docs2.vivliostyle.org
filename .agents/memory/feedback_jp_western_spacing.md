日本語と欧文（アルファベット・数字など）の境目に半角スペースを入れる慣習は、本プロジェクトでは **採用しない**。レビューやリファクタで「`Vivliostyle CLI生成物` を `Vivliostyle CLI 生成物` にすべきでは」のような提案があっても **適用しない**（むしろ削除する）。

**Why:** ユーザーから「多くのブラウザは既に和欧間隔を実装しており、以前のように和欧間に半角スペースを挿入する意義はありません」と明確に方針提示があった（Copilot レビューが #10 として半角スペース追加を提案した際、棄却の判断とともに）。CSS の `text-spacing-trim` / `text-autospace` 等の機能でブラウザ側が処理するという理解に基づく。

**How to apply:**
- 自動的に半角スペース挿入を提案・適用しない
- レビュアーから半角スペース挿入を提案された場合も、本方針に従って棄却する旨を返答する
- 既に半角スペースが入っている箇所は触らない（過剰に削除はしない）
